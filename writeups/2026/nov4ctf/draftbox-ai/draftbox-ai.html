CTF WRITEUP / Nov4CTF

DraftBox AI.

Trace an internal archive job to the restricted CSV downloaded by a browser session.

Forensics · EasyNov4CTFNovember 27–28

The challenge

DraftBox AI lets users create, edit, and download documents in chat. The security team spotted an unusual request to the internal document repository and suspected a confidential file had leaked into a user’s session. Analyze last_shift.pcapng, trace the session, and identify the exact filename that was downloaded.

Original challenge PCAP (last_shift.pcapng)

Find the archive request

The challenge asked which restricted file a DraftBox worker fetched and passed to a user’s chat session. In last_shift.pcapng, the Wireshark display filter http.host == "archive.draftbox.test" isolates the sole request to the archive. Frame 13731 requests /objects/9f3b. Frame 13732 returns HTTP 200, marks the file as restricted, and names it model-access-review.csv in the attachment header.

Follow the job into the chat

Searching the capture for job ID j_7da93588652930cd leads to frame 13738. That response completes the chat request from frame 13727 and assigns the file artifact ID a_ca51a39eb3f7c4b0. In frame 20690, the browser requests the download for that artifact using the same session cookie as the original chat request.

Verify the download

Frame 20694 returns HTTP 200 and names model-access-review.csv in its attachment header. The archive and download responses each contain 224 bytes, and their SHA-256 digests match. That confirms the browser received the same restricted file.

Recovered flag

NVR{model-access-review.csv}
