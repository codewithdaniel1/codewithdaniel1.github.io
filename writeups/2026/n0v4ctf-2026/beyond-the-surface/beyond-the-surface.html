Beyond the Surface.

Decode a GIF comment and reconstruct the flag from a five-by-five pixel font.

ForensicsEasyChallenge by zeroD

Inspect the GIF

The ZIP contained a single animated GIF. The animation appeared to show a security camera. Running exiftool -b -Comment chall.gif revealed a GIF comment containing eval(atob("…")). The atob call identified the quoted text as Base64.

Reconstruct the lettering

Decoding the Base64 as text revealed JavaScript that draws characters on a canvas. The array named m stores each character as five numbers. Each number describes one row of a five-by-five pixel grid. For example, the row value 17 becomes 10001 in binary, lighting the first and last pixels.

I read the top row across all characters, then repeated the process for each of the remaining four rows. The reconstructed message included two digits that are easy to misread. Both 1 characters have a base, and the 0 in N0T has a diagonal stroke.

Recovered flag

NVR{G1F_1S_N0T_HTML}
