CTF WRITEUP / N0v4CTF 2026

“TQ” Specialized High School.

Normalize a noisy scoreboard, verify its audit signatures, and document the unsolved encryption step.

CryptographyListed as EasyChallenge by Kazuto

Normalize the scoreboard

The archive presents a suspicious wave of perfect scores after an appeals review. It contains a scoreboard, a signed audit log, an evidence note, and five AES-256-GCM records. The evidence note gives Tuyên Quang’s province code as 22. Applying Unicode NFKC normalization and removing invisible formatting characters left exactly one scoreboard record with PROV-22. Data row 192 lists student code STU-51a01315 and audit tag 961bc53145ba.

Verify the audit records

All 120 signatures verified against four secp256k1 public keys when the signed text was formatted as student_id|old_score|new_score|timestamp. For example, the first row signs HS613215|5.5|10.0|1784405888. Each row also contains a LEAK-… label after normalization. That label lies outside the signed text, so the signature check leaves it unauthenticated.

Check the remaining clues

The province-22 row contains a 40-character encoded note, and the evidence file supplies 14 more strings. Standard basE91 changes the province note when it is decoded and re-encoded as written. Candidate AES keys derived from the public clues produced no plaintext with the expected flag prefix. How the numbered strings connect the audit data to the AES key remains unresolved.

No verified flag.
